Retrieval-Augmented Generation, or RAG, is a technique that combines information retrieval with text generation. Instead of relying solely on what a language model learned during training, a RAG system fetches relevant information from an external knowledge source at answer time and feeds it into the model as context.

The typical RAG pipeline has three stages. First, documents are split into small chunks and converted into vector embeddings, which are numerical representations that capture the meaning of the text. Second, these embeddings are stored in a vector database that supports fast similarity search. Third, when a user asks a question, the question itself is embedded and used to search the vector database for the most relevant chunks.

Once the relevant chunks are retrieved, they are inserted into the prompt sent to a language model, along with the original question. The language model then generates an answer that is grounded in the retrieved content rather than purely in its own internal knowledge. This reduces hallucination and allows the system to answer questions about private or recently updated information that the model was never trained on.

Common use cases for RAG include customer support chatbots that answer questions from a company's internal documentation, research assistants that summarize findings from a set of papers, and enterprise search tools that let employees ask natural language questions about internal policies. Improvements to a basic RAG system often include hybrid search that combines keyword and vector search, re-ranking retrieved chunks with a cross-encoder model, and experimenting with different chunk sizes to balance context length against retrieval precision.
